This page contains an (incomplete) list of freely redistributable software
which is known to run in CMUCL. To know what platforms CMUCL runs on, see
the [platforms page]({{ '/platforms.html' | relative_url }}).

For the most current porting information, see the
[CMUCL GitLab Wiki](https://gitlab.common-lisp.net/cmucl/cmucl/-/wikis/ports).

- **[Araneida](http://www.cliki.net/Araneida)** — a small extensible web
  server written in Common Lisp with CMUCL extensions, under a
  BSD-sans-advertising licence.
- **CL-HTTPD** — an advanced web server implemented in Common Lisp.
- **[CLORB](http://www.cliki.net/CLORB)** — a CORBA ORB for Common Lisp.
- **[CLiki](http://www.cliki.net/)** — a wiki-like system allowing
  collaborative web authoring, developed in CL.
- **CLX** — an implementation of the client side of the X11 protocol in
  Common Lisp.
- **[McCLIM](http://mcclim.cliki.net/)** — a rapidly improving free
  implementation of the CLIM specification.
- **[Garnet](http://www.cs.cmu.edu/afs/cs/project/garnet/www/garnet-home.html)**
  — a sophisticated widget set developed at the User Interface Software
  Group at Carnegie Mellon University.
- **CLM** — a Motif® subsystem for CMUCL. Can be compiled with the freely
  available LessTif implementation.
- **[f2cl](http://www.cliki.net/f2cl)** — a Fortran to Common Lisp compiler
  that translates Fortran 77 to fairly readable Common Lisp.
- **[MatLisp](http://matlisp.sourceforge.net/)** — a matrix package for
  Common Lisp. Consists of CLOS bindings to the BLAS and LAPACK linear
  algebra packages.
- **[Maxima](http://maxima.sourceforge.net/)** — a computer algebra system
  implemented in Common Lisp. A derivative of the Macsyma system, released
  under the GNU GPL.
- **[ACL2](http://www.cs.utexas.edu/users/moore/acl2/)** — a semi-automatic
  theorem prover embedded in an applicative dialect of Common Lisp.
- **[CL-XML](http://www.cliki.net/CL-XML)** — implements data stream parsing
  and serialization for the XML, XML Query and XPath standards.
