To search the CMUCL site and wiki, please use the following resources:

- [CMUCL GitLab Wiki](https://gitlab.common-lisp.net/cmucl/cmucl/wikis/home)
  — searchable via GitLab's built-in search
- [CMUCL Issue Tracker](https://gitlab.common-lisp.net/cmucl/cmucl/issues)
  — search existing bug reports and feature requests
- [CMUCL GitLab repository](https://gitlab.common-lisp.net/cmucl/cmucl)
  — search the source code

You can also use a web search engine with `site:cmucl.org` to restrict
results to this site. For example:

```
site:cmucl.org unicode
```
