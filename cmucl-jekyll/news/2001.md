**2001-12-20**
: Experimental binaries, similar to the upcoming 18d release, are available in
  the `binaries` directory of the [download sites]({{ '/download.html' | relative_url }}).

**2001-12-10**
: Experimental binaries for OpenBSD/x86 have been uploaded to the `experimental`
  directory of the download sites.

**2001-08-15**
: A number of [mirror sites](https://cmucl.org/mirrors.html) have been made
  available.

**2001-07-26**
: The primary CMUCL server was taken offline unexpectedly, due to a move of the
  hosting company. The mailing lists are still running, but CVS and FTP/HTTP
  downloads are currently unavailable.

**2001-07-16**
: Added pointer to [PGPLOT-CL](http://www.geocities.com/pgplot_cl/) to the Ports
  page.

**2001-07-05**
: Improvements to the way subsystems are loaded: the `modules:` pathname is
  initialized correctly, to make things like `(require :clx-library)` work.

**2001-06-28**
: Various ANSI compliance fixes: `:CLTL2`, `:DRAFT-ANSI-CL`, `:X3J13` features
  removed. Changes in the precedence lists of certain conditions.

**2001-06-19**
: Beginnings of a [FAQ]({{ '/FAQ.html' | relative_url }}).

**2001-06-17**
: A new version of the [EncyCMUCLopedia](https://www.pvv.ntnu.no/~ljosa/doc/encycmuclopedia/)
  (compendium of documents related to CMUCL) has been released.

**2001-06-12**
: New web pages go live.

**2001-06-11**
: Bugfix for printing of bit vectors (printer was incorrectly respecting radix
  and base control variables). Also bugfixes to pretty printing of vectors.

**2001-06-03**
: Changes to `DEFMACRO` processing, to improve ANSI compliance. It now has
  compile-time effect only when at top-level.

**2001-05-13**
: Improvements to disassembly listings on x86 and SPARC.

**2001-05-03**
: Linux RPMs available at [rpmfind.net](http://rpmfind.net/linux/rpm2html/search.php?query=cmucl).

**2001-04-25**
: Changes to PCL (the CLOS implementation included with CMUCL) to remove code
  for other Common Lisp implementations.

**2001-04-12**
: CMUCL is reported to segfault on Linux 2.2 with the bigmem patch and the
  `CONFIG_2GB` option. It works ok using the option `CONFIG_1GB`.

**2001-03-20**
: Changes to `PROCLAIM` and `DECLAIM` to be more ANSI-compliant. `PROCLAIM` no
  longer has a compile-time effect, so many old uses of this should use
  `DECLAIM` instead.

**2001-02-10**
: A PowerPC backend has been contributed by Gary Byers. Work is underway to
  revive the code.

**2001-01-08**
: A port of the **XML parser** from [Franz Inc](http://www.franz.com/) is
  available from [ports/xmlutils](ftp://ftp2.cons.org/pub/lisp/cmucl/ports/xmlutils/).
