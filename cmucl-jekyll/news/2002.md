**2002-12-24**
: A new version of GerdsPCL has been uploaded to the experimental directory of
  the download mirrors. This version includes an optimization that can make class
  slot access as efficient as for structures.

**2002-12-15**
: Documentation: a new document giving [hints on using the PCL MOP](https://cmucl.org/doc/pcl-mop-hints.html)
  has been put online.

**2002-12-19**
: Binaries for x86-linux, x86-freebsd and sparcv9-solaris from current source
  have been uploaded to the binaries directory of the download sites.

**2002-11-18**
: Binaries featuring the "gerdspcl" version of PCL have been uploaded to the
  experimental directory of the download sites.

**2002-11-13**
: An updated version of the [*CMUCL User's Manual*](https://cmucl.org/docs/cmu-user/html/index.html)
  has been uploaded to the documentation section, in HTML, PDF and Postscript
  formats.

**2002-11-09**
: A tarball containing the revamped source to PCL (the CLOS implementation in
  CMUCL) is available in the experimental directory of the download sites.

**2002-11-01**
: The profiler now reports precise measurements of allocation on x86 platforms
  using the generational garbage collector.

**2002-10-24**
: The linkage-table feature has been ported to SPARC by Raymond Toy. This means
  that it works on all currently supported platforms.

**2002-10-02**
: A Karatsuba multiplier implementation has been added for bignums, which should
  speed up multiplications for bignums with more than 512 bits.

**2002-09-04**
: Initial support for 64-bit integers on sparc-v8plus architectures (basically
  UltraSPARC machines) has been added by Raymond Toy.

**2002-08-27**
: On FreeBSD and Linux on x86 architectures, there has been a change to the way
  that foreign symbol addresses are resolved. An extra level of indirection, via
  a linkage table, has been added. This work is due to Tim Moore.

**2002-08-25**
: There have been a large number of bugfixes, ANSI compliance fixes, unused code
  deletion and cleanup of the PCL code in CMUCL, thanks to Gerd Moellmann.

**2002-08-20**
: The nasty bug in inappropriate code deletion when using `FLET` or `LABELS` has
  been fixed, thanks to Alexey Dejneka.

**2002-08-07**
: Binaries for NetBSD 1.5.2 on x86 have been uploaded to the experimental
  directory of the download site.

**2002-04-25**
: Updated extra tarballs for 18d on x86/linux. If you use Hemlock on this
  platform you should reinstall the extra tarball; the previous ones were broken.

**2002-04-11**
: CMUCL version 18d released. See the [release notes](https://cmucl.org/news/release-18d.txt)
  for details of all the new features and bugfixes.

**2002-03-13**
: Fix for dynamic loading in FreeBSD 4.0 and later.

**2002-02-06**
: Allow users to disable tail-call optimization by setting a debug optimization
  quality higher than 2.

**2002-01-27**
: Changes to the compile-time behaviour of `DEFCONSTANT`, to fix its behaviour
  when it is not at the toplevel.

**2002-01-13**
: Add the ability to select rounding precision for x86 floating point operations.

**2002-01-23**
: Anoncvs access is available again.

**2002-01-22**
: Experimental NetBSD/x86 binaries are available in the `experimental` directory
  of the [download sites]({{ '/download.html' | relative_url }}).
