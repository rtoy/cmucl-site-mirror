**2009-10-29**
: CMUCL has a faster unicode reader now. Tests show that CMUCL can process utf8
  streams up to two times faster. A serious bug in SSE2 support has been fixed.
  (The sum or difference of a complex and a float would sometimes produce an
  incorrect imaginary part.)

**2009-10-02**
: **CMUCL 20a patch 000** A serious bug in the printer was found in the Unicode
  builds. The bug caused `'|\||` (vertical bar) and `'|\`|` (backquote) to be
  printed without escapes. This
  [patch](https://cmucl.org/downloads/release/20a/patches/cmucl-20a-patch-000.tar.gz)
  can be used to fix this issue. See [Install]({{ '/install.html' | relative_url }})
  for instructions on how to apply a patch.

**2009-09-30**
: **CMUCL 20a is released.** The [release notes](https://cmucl.org/news/release-20a.txt)
  and binaries for the supported platforms are available from the `release/20a`
  directory of the [download]({{ '/download.html' | relative_url }}) sites. Due
  to the 20a release, no snapshots are available for 2009-10.

**2009-09**
: CMUCL 20a pre-release 1 is available.

**2009-05**
: The first builds with Unicode support are available. These builds have support
  for Unicode that is mostly working.

**2009-03**
: **CMUCL 19f has been released.** The [release notes](https://cmucl.org/news/release-19f.txt)
  and binaries for the supported platforms are available from the `release/19f`
  directory of the [download]({{ '/download.html' | relative_url }}) sites. Due
  to the 19f release, no snapshots are available for 2009-03.

**2009-02-09**
: The **February snapshot binaries** have been uploaded to the
  `snapshots/2009-02` directory of the download sites.

**2009-01-09**
: The **January snapshot binaries** have been uploaded to the `snapshots/2009-01`
  directory of the download sites.

  These snapshots include support for X87 and SSE2. CMUCL will automatically
  detect if the chip supports SSE2 or not. If so, the SSE2 core will be used.
  If not, the X87 (legacy) core will be used. The SSE2 core should work somewhat
  better than the X87 core on chips that support both.

**2009-01**
: Fred Lakin, a long-time CMUCL user, has written a novel called
  [Live Graphics Nightly](http://www.livegraphicsnightly.com). He has a nice
  acknowledgement to all of the CMUCL implementors and maintainers.
