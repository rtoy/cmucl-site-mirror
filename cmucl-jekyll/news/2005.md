**2005-11-17**
: **CMUCL 19c has been released.** The release notes and binaries for the
  supported platforms are available from the `release/19c` directory of the
  download sites. (Due to problems in the release process, CMUCL 19b was never
  officially released.)

**2005-06-02**
: The **first 19b release-candidate binaries** have been uploaded to the
  `release/19b/pre-release` directory of the download sites. Please test these
  binaries!

**2005-05-05**
: The **May snapshot binaries** have been uploaded to the `snapshots/2005-05`
  directory of the download sites.

**2005-04-05**
: The **April snapshot binaries** have been uploaded to the `snapshots/2005-04`
  directory of the download sites.

**2005-03-06**
