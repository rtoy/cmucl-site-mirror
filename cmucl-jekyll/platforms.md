CMUCL runs on most major Unix platforms. For the most current list of
supported platforms, see the
[CMUCL GitLab Wiki](https://gitlab.common-lisp.net/cmucl/cmucl/wikis/home).

Historically supported platforms include:

- Linux x86 (32-bit, Unicode and non-Unicode, x87 and SSE2 floating point)
- Mac OS X (Darwin) x86
- FreeBSD x86 (SSE2 only in recent snapshots)
- Solaris/SPARC (sparcv9) and Solaris/x86
- NetBSD x86
- PowerPC/Darwin (ppc) — revived in the 2012-04 snapshot; Unicode only

For platform-specific information, see the
[architecture-specific documentation](https://cmucl.org/doc/arch.html).

See the [download page]({{ '/download.html' | relative_url }}) for
binaries for each supported platform.
