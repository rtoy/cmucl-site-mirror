Hemlock is the integrated editor which comes with CMUCL. It is an Emacs-like editor implemented in Common Lisp.

Documentation for Hemlock:

  • The Hemlock User's Manual:
    • HTML version all on one page for online browsing
    • HTML version on multiple pages for online browsing
    • PDF (US letter size) with embedded hyperlinks
    • Tarball of the info files for local use with emacs
  • The Hemlock Command Implementor's Manual:
    • HTML version all on one page
    • HTML version on multiple pages
    • PDF (US Letter size)
    • Tarball of the info files for local use with emacs
  • The original Scribe versions (of historical interest):
    • Hemlock User's Manual (Postscript)
    • Hemlock Command Implementor's Manual (Postscript)

For the latest information on Hemlock, see the CMUCL GitLab Wiki.
