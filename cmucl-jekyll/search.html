To search the CMUCL site and wiki, please use the following resources:

  • CMUCL GitLab Wiki — searchable via GitLab's built-in search
  • CMUCL Issue Tracker — search existing bug reports and feature requests
  • CMUCL GitLab repository — search the source code

You can also use a web search engine with site:cmucl.org to restrict results to this site. For example:

   site:cmucl.org unicode
