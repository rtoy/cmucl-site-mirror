CMUCL has been ported to a number of hardware and operating system combinations. For the most current porting information, see the CMUCL GitLab Wiki.

Current and historical ports include:

  • x86/Linux — the most actively maintained port, available in both Unicode and non-Unicode variants, with x87 and SSE2 floating point
  • x86/Darwin (Mac OS X) — Unicode and non-Unicode
  • x86/FreeBSD — SSE2 only in recent snapshots
  • x86/NetBSD — Unicode and non-Unicode
  • x86/Solaris
  • SPARCv9/Solaris — Unicode and non-Unicode
  • PowerPC/Darwin — revived in the 2012-04 snapshot; Unicode only

For information on porting CMUCL to a new platform, see the FAQ (particularly the question on how difficult it is to port CMUCL) and the Developer documentation.
