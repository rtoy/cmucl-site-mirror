CMUCL runs on most major Unix platforms. For the most current list of supported platforms, see the CMUCL GitLab Wiki.

Historically supported platforms include:

  • Linux x86 (32-bit, Unicode and non-Unicode)
  • Mac OS X (Darwin) x86
  • FreeBSD x86
  • Solaris/SPARC (sparcv9) and Solaris/x86
  • NetBSD x86
  • PowerPC/Darwin (ppc)

For platform-specific information, see the architecture-specific documentation.

See the download page for binaries for each supported platform.
